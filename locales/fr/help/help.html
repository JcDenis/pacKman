Emballer
Cochez des plugins ou des thèmes, puis cliquez sur « Emballer les modules sélectionnés ». Un paquet zip est créé dans le dépôt pour chaque nom de paquet configuré.
Dépôt de paquetages
Cet onglet liste les paquets créés. Choisissez une action pour les paquets cochés : supprimer, copier ou déplacer vers le dossier des plugins ou des thèmes. « Sélectionner les versions anciennes » coche les paquets qui ne sont pas de la dernière version. Dans l'onglet « Racine des plugins » ou « Racine des thèmes », l'action « installer » installe le paquet.
Configuration
Le lien « Configurer le plugin » règle le dossier du dépôt (par défaut, le dossier VAR de Dotclear), le nom des paquets (%type%, %id%, %version%, %author%, %time%), l'écrasement des paquets existants, les fichiers à exclure (séparés par des virgules), le retrait des commentaires et la correction des fins de ligne.
