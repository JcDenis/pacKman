Pack up
Check plugins or themes, then click "Pack up selected modules". A zip package is created in the repository for each configured package name.
Packages repository
This tab lists the created packages. Choose an action for checked packages: delete, copy or move to the plugins or themes directory. "Select non lastest versions" checks the packages that are not of the latest version. In the "Plugins root" or "Themes root" tab, the action "install" installs the package.
Configuration
The link "Configure plugin" sets the repository directory (by default the Dotclear VAR directory), the package names (%type%, %id%, %version%, %author%, %time%), the overwriting of existing packages, the files to exclude (separated by commas), the removal of comments and the fix of line endings.
